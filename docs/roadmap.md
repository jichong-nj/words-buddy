## 2. 各模块待决策清单

下面每一项都是**会改变表结构或接口**的决策，不是实现细节。过完一个模块我就写一份需求文档。

### M3 背单词 / 学习

| # | 待决策 | 选项与影响 |
|---|---|---|
| 3.1 | 复习算法 | **简化分级**（生/识/熟，间隔 1-2-4-7-15 天，实现简单可解释）／ SM-2（经典，参数可调）／ FSRS（最准，需引入算法库与更多日志字段） |
| 3.2 | 学习单位 | 整词（体感简单）／ 义项级（精确但卡片变多） |
| 3.3 | 卡片交互形式 | 看词回忆释义、看释义回忆词、听音选义、听音拼写、例句挖空——选哪几种进第一期 |
| 3.4 | 评分按键 | 三档「忘记 / 模糊 / 认识」／ 四档（加「完全记住」）／ 二档（认识/不认识） |
| 3.5 | 每日任务量 | 新词上限 + 复习上限，是否允许学生自设，是否允许「清空今日任务」模式 |
| 3.6 | 学习范围 | 整库顺序 / 随机 / 按主题 / 管理员指定区间（如第 1–100 词） |
| 3.7 | **发音方案** | 浏览器 `speechSynthesis`（**完全离线、零依赖**，音质取决于系统语音包）／ 预置 mp3 词库（体积大、需匹配）／ 在线 TTS（违背离线原则，不推荐） |
| 3.8 | 「一天」的定义 | 自然日 0 点重置 ／ 凌晨 4 点（避免深夜复习跨天）／ 滚动 24 小时 |
| 3.9 | 卡片正反面内容 | 正面：单词 + 音标 + 音频；背面：主义项 + 例句。是否默认显示例句、是否显示英文释义 |
| 3.10 | 断点与撤销 | 复习中途退出是否保留进度；误按「认识」能否撤销（建议给 5 秒 undo） |

**预留表**：`word_progress(user_id, word_id, status, ease, interval_days, due_at, last_review_at, review_count, lapses, created_at, updated_at)` + `review_log(id, user_id, word_id, rating, reviewed_at, duration_ms)`。

### M4 练习与考试

| # | 待决策 | 选项与影响 |
|---|---|---|
| 4.1 | 题型清单 | 中译英单选、英译中单选、听音选义、听写拼写、例句挖空、义项连线匹配、中英配对——第一期做哪几种 |

## 3. 跨模块的公共约定（先定下来，避免各模块各写一套）

| 约定 | 建议 |
|---|---|
| 主键 | 全部 `INTEGER PRIMARY KEY AUTOINCREMENT` |
| 时间 | 统一 `TEXT`，格式 `YYYY-MM-DD HH:MM:SS`，`localtime`，写入用 `datetime('now','localtime')` |
| 软删除 | 仅 `word_bank.status` 与 `app_user.status` 用状态位，其余表硬删 |
| 布尔 | `INTEGER 0/1`，命名前缀 `is_` / `needs_` |
| JSON 列 | 命名后缀 `_json`，只存不参与查询的字段 |
| 枚举 | 用 `TEXT` + 应用层校验，不用 SQLite `CHECK`（改枚举不必迁移） |
| 外键 | 一律 `ON DELETE CASCADE`，且启动时 `PRAGMA foreign_keys = ON` |
| 分页 | `page` 从 1 起，`size` 默认 20、上限 100 |
| 错误响应 | `{ code: string, message: string, details?: any }`，HTTP 状态码语义化 |
| 主题枚举 | **剑桥官方 Topic 体系**（KET 24 / PET 22），代码常量 `shared/topic-taxonomy.ts`，不建表；`word.topic` 存官方英文名原文。详见 [cambridge-topics.md](./cambridge-topics.md) |
